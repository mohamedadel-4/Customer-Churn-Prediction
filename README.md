# Customer Churn Prediction

A Machine Learning project for analyzing customer behavior and predicting customer churn.

## Project Overview

This project analyzes customer data to identify customers who are likely to leave a service.

The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine Learning models
- Customer churn prediction
- Customer segmentation
- Revenue analysis
- Anomaly detection

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Files

| File | Description |
|---|---|
| `customer_360_ml.ipynb` | Main Machine Learning notebook |
| `customer_360_ml_workshop.csv` | Customer dataset |
| `customer_360_predictions.csv` | Model predictions |

## Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Churn Prediction

## Results

The trained Machine Learning pipeline is used to predict customer churn and support customer behavior analysis.
